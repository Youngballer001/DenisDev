## Running Locally

You can run this project locally using a web server such as XAMPP.

1. Clone the repository:

   ```bash
   git clone https://github.com/Youngballer001/denis-portfolio.git
   ```

2. Move the project folder into your XAMPP `htdocs` directory.

3. Start Apache from the XAMPP Control Panel.

4. Open your browser and visit:

   ```text
   http://localhost/denis-portfolio/
   ```

No additional package installation is required.
